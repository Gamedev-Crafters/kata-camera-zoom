[Test]
public void IdealGoal()
{
    // red thing is small and to the left
    // put cursor in left side
    // zoom in
    // red thing should now be big and in the center

    // red thing is big and in the center
    // put cursor in right side
    // zoom out
    // red thing should now be small and on the right
}


"red thing is small and to the left" es descriptivo, nos sirve como assert 
pero no como arrange, asi que cambiamos el arrange para que este en el
lenguaje de nuestro dominio: world units

no tenemos un dominio para "seen from the camera", asi que nos lo inventamos;
la mejor opcion es "el rectangulo relativo al viewport", en el rango [0,1] x [0,1]

toca definir qué es una cámara y cómo construirla. Por definición, solo necesitamos
las coordenadas reales y relativas de un mismo objeto.

añadimos tests concretos para la creacion de camaras

la situacion más sencilla es cuando las coordenadas relativas son precisamente la pantalla completa

la siguiente situacion más sencilla es cuando las coordenadas relativas son precisamente la mitad vertical de la pantalla completa

después, la otra mitad vertical

por ultimo, la mitad vertical central

probemos la generalización natural!

repetimos: buscamos el siguiente hardcodeado que nos permita avanzar, en el que cambie
el numero que queremos generalizar

una vez tenemos varias generalizaciones, podemos generalizar entre ellas

Ahora que podemos crear cualquier camara, toca implementar el zoom.
Seguimos la misma estrategia:
- escribir el codigo ideal
- hacer tests con valores hardcodeados sencillos
- generalizar a partir de estos valores

De hecho, hay otros dos caminos:
- usar invariantes: antes y despues del zoom, .toScreenCoords(cursor) debe ser el mismo. De ahi podemos ir despejando variables.
- usar el método ya hecho: la camara que buscamos es aquella que transforma el cursor original en uno con la misma posicion pero distinto tamaño.
Tomamos este último camino por ser el más rápido para la implementación, y usamos las invariantes para testearlo.
